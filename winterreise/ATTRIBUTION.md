# Schubert Winterreise Dataset — attribution and licence

## Source

**The Schubert Winterreise Dataset** is a multimodal dataset for the analysis of Schubert’s Winterreise song cycle:

- Dataset: <https://zenodo.org/records/4122060>
- Publication: Weiss, Zalkow, Arifi-Müller, Müller, Koops, Volk and Grohganz, “Schubert Winterreise dataset: A multimodal scenario for music analysis” (JOCCH, 2021)

The corpus contains paired audio, score and annotation material for a set of Winterreise songs, designed for multimodal music analysis and alignment tasks.

## What is here

| Folder | Files | Origin |
| --- | --- | --- |
| `audio/` | 48 mp3 | Winterreise performance recordings |
| `score/` | 48 MusicXML/XML | Scores for the songs in the dataset |
| `annotations/` | 48 TSV | Performance-to-score alignment annotations |

The metadata index in `metadata-winterreise.csv` is the authoritative list of the files in this folder.
